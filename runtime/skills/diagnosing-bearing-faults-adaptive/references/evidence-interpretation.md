# v2 证据解释

- 谐波命中、局部显著性、跨带证据等级来自本次数值工具；不是概率。
- 质量门、跨频带和分段检查的冲突或缺失必须披露。
- 三族无支持不能普遍证明设备健康；normal 只覆盖当前测量范围和灵敏度。
- 状态驱动处理可能改善或损失信息，baseline 可胜出；不得宣称自适应必然提高准确率。
- 工具提供当前样本的测量和候选证据，模型按[诊断判据](diagnosis-criteria.md)综合判断。

## 从测量到解释

1. 核对本次输入的采样率、转速、轴承几何或显式频率比、记录长度和信号单位。转速以实际采用值为准；输入标称转速、频谱估速和实测转速按记录区分。只有工具实际执行且返回结果时才说明估速、同步扣除或阶次跟踪。采用转速不等于实测相位。
2. 先看质量门、有效频带及谐波覆盖，再解释实际峰。可观测但未检出、有峰但未过筛、频带不覆盖、工具未运行的含义各不相同。摘要中的代表峰、频带计数或最大 FFT 点不能替代完整频带的匹配记录。
3. 对关键频带说明故障基频、谐波阶次、理论峰位、实测峰位及适用容差。拟合得到的间隔与单个实测峰相对目标的偏差分别解释。若已有转频竞争、跨带支持或频率碰撞记录，说明它怎样影响归属。多个频带可分别提供支持，同一组的阶次必须来自同一频带、同一包络方式。
4. 检查实际采用了哪条处理路径及是否回退。保留原始量和处理量的来源及单位。原始量按本次计量尺度解读；未知单位或归一化幅值不能换写为加速度、速度或电压。局部稳健 z 是峰相对局部背景的量，不能当成故障概率。
5. 说明实际的一致性和冲突。说明各有效分段的支持程度，以及是否出现竞争故障族。分段检查未触发时记录原因。若存在未解决的分类疑点，指出对应的观测和证据缺口，供复核。
