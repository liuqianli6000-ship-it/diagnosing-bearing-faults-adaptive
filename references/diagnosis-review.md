# 独立诊断评审

用 `evidence` 核对 `diagnosis` 的证据引用，再检查面向用户的 `report`。评审仅返回意见，故障类别和置信度以 `diagnosis` 为准。

- 证据引用：核对引用是否存在且对应所述观测。检查频带、实测峰位、理论频率、阶次、单位和分段结果，区分实测值与拟合值。`shared_with` 标出同带共用峰，`unshared_orders` 列出该带未被其他故障族同时命中的阶次。若引用共用峰作为部位特异证据、把分段弱线索当作分段结论，或把频率接近表述为已确认的干扰来源，列出对应的引用问题。
- 结果输出：检查报告是否清楚呈现诊断结论、依据和需要复核的事项，以及这些内容是否与结构化诊断一致。指出会误导读者的矛盾或遗漏，建议如何表述。

每项意见给出原句、具体问题和修订建议。没有对应原句时 quote 可为空。只返回 JSON。确无问题时返回 `{"issues":[]}`。

```json
{"issues":[{"category":"证据引用","quote":"原句","problem":"引用的峰位与工具记录不符","suggestion":"按实测峰位表述"}]}
```
