# 轴承领域规则（精简）

- **BPFO** = 外圈故障特征频率：外圈缺陷，包络谱常出现 BPFO 及其整数倍谐波，冲击较稳定。
- **BPFI** = 内圈故障特征频率：内圈缺陷，常带转频边带调制。
- **BSF** = 滚动体故障特征频率：滚动体缺陷，能量通常较弱，可带保持架（FTF）边带。
- 故障特征频率 = 故障频率比 × 转频(Hz)；故障频率比可由显式比例或几何
  （滚动体直径 d、节圆直径 D、滚动体数 n、接触角 α）计算。
- 转频及其谐波、齿轮啮合、电气干扰不应误判为轴承故障特征频率。

## 技术依据

- [ISO 13373-3:2015，附录 D 滚动轴承振动诊断](https://www.iso.org/standard/40840.html)用于核对诊断流程和特征频率的物理意义。
- [Randall 与 Antoni，Rolling element bearing diagnostics](https://doi.org/10.1016/j.ymssp.2010.07.017)讨论包络解调、轴承周期冲击与齿轮信号掩蔽。项目实际使用的参数和带数见[频率匹配](frequency-matching.md)。
