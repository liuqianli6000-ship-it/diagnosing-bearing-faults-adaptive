# 信号分析输出

按请求执行时域、频域或时频域测量。独立脚本输出 `signal-analysis/v1`，包含 `assessment.quality` 和实际执行的 `time_domain`、`frequency_domain` 或 `time_frequency`。生成的图片逐项列在 `analysis_plots`，图片位于 `plots/`。STFT 有效时保存时频图。

- **时域**描述均方根、峭度、峰值因子、波形趋势等已测结果。
- **频域**报告实测主峰频率、相对幅值和谱峰信噪比。
- **时频域**报告频率能量随时间的变化和高能量帧。

提供测量结果和对应图片。单域分析的结论描述当前信号特征，故障类型由完整诊断流程给出。
